# Checklist de Grabación

## Antes de grabar

- Revisar que el micrófono funcione.
- Usar zoom suficiente para que el código se lea.
- Cerrar notificaciones.
- Abrir el editor online.
- Probar el código antes de grabar.
- Tener el guion a la mano.
- Confirmar que el ejemplo corresponde a la lección.

## Durante la grabación

- Hablar despacio.
- Usar lenguaje simple.
- Evitar jerga innecesaria.
- Explicar cada línea importante.
- Hacer pausas para práctica.
- Recordar que no se necesita instalar nada.
- No mencionar autores ni branding personal.

## Después de grabar

- Revisar audio.
- Revisar que el texto sea legible.
- Revisar que el video no esté acelerado.
- Subir a YouTube como no listado.
- Pegar el enlace en `course-plan.md`.
- Pegar el enlace en `videos/youtube-links.md`.
